# OpenCart E-Commerce Manual Testing Project

## Project Overview

This project demonstrates my practical knowledge of Manual Testing by testing the OpenCart E-Commerce application.

The project covers the complete software testing process, including requirement analysis, test planning, test scenario design, test case creation, test execution, defect reporting, and requirement traceability.

The objective of this project is to identify defects, verify application functionality, and ensure that the application meets the specified requirements.

---

## Application Under Test

**Application Name:** OpenCart E-Commerce Application

**Application Type:** Web Application

**Testing Type:** Manual Testing

**Tested Areas:**
- User Registration
- Login
- Product Search
- Product Details
- Shopping Cart
- Checkout Process
- My Account
- Wishlist
- Product Comparison
- Logout

## Key Testing Areas

### User Registration

Tested the registration functionality using valid and invalid user details.

### Login

Verified login functionality using valid and invalid credentials.

### Product Search

Tested product search functionality using valid, invalid, and partial search inputs.

### Shopping Cart

Verified adding, updating, and removing products from the shopping cart.

### Checkout

Tested the end-to-end checkout process.

### My Account

Verified account-related functionalities available to registered users.

### Wishlist

Tested adding and removing products from the wishlist.
